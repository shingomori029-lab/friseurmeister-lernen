# Friseurmeister lernen

マイスター試験（美容師／Friseurhandwerk）のための勉強アプリ。
Teil II（専門理論）、Teil III（経営・法律）、Teil IV（AEVO）に対応しています。

HTML／CSS／JavaScript だけで動きます。ビルド不要、外部サービスへの通信なし。
学習データはブラウザの localStorage にだけ保存されます。

## 機能

- **4択クイズ** – パート・分野・問題数を選んで出題。答えるとすぐに正解と解説を表示
- **単語カード** – 専門用語をめくって覚える。「覚えた」は 1 → 3 → 7 → 14 → 30 日後に再出題（Leitner方式）
- **模擬試験** – 最大30問・1問90秒の制限時間。最後に採点し、分野別の結果と見直しを表示
- **記録** – 連続日数、14日間の学習量、分野別の習得度、模試の履歴
- **日本語訳** – 問題はドイツ語。右上の「訳」で全体、各問題の「日本語訳」でその問題だけ訳を表示

## 構成

```
friseurmeister-lernen/
├── index.html
├── css/app.css
├── js/
│   ├── registry.js       # 名前空間 FM とデータ登録用の関数
│   ├── data/             # 問題と単語カード（ここを編集して問題を追加）
│   ├── store.js          # 学習データの保存（localStorage）
│   ├── app.js            # ルーター・共通部品・訳の切り替え
│   └── views/            # 画面ごとの処理（home, quiz, cards, exam, stats）
├── sw.js                 # オフライン対応
├── manifest.webmanifest
└── icon.svg / icon-512.png
```

## 問題を追加する

`js/data/` のファイルに1行ずつ追加します。**正解は必ず1番目**に書きます（表示時にシャッフルされます）。

```js
["ドイツ語の問題文", "日本語の問題文",
 ["正解", "誤答", "誤答", "誤答"],
 ["正解（訳）", "誤答（訳）", "誤答（訳）", "誤答（訳）"],
 "ドイツ語の解説", "日本語の解説"],
```

新しい分野は `FM.addQuestions(パート番号, "キー", "分野名DE", "分野名JA", [ ... ])` で作れます。
単語カードは `js/data/cards.js` に `["der Begriff", "日本語", "kurze Erklärung"]` の形で追加します。

> 既存の問題の**途中に**行を挿入したり削除したりすると、その後ろの問題の学習記録がずれます。追加は各分野の末尾に。

新しいファイルを作ったら `index.html` の `<script>` と `sw.js` の `ASSETS` にも追加してください。

## 起動

```bash
python3 -m http.server 8767 --directory friseurmeister-lernen
```

ブラウザで http://localhost:8767 を開きます。

## iPhone で使う

GitHub Pages で公開しています：
**https://shingomori029-lab.github.io/friseurmeister-lernen/**

iPhone の Safari で開いて「共有」→「ホーム画面に追加」。一度開けばオフラインでも使えます。

変更を反映するには、コミットして push するだけです（1〜2分で公開サイトに反映）。

```bash
git add -A && git commit -m "Fragen ergänzt" && git push
```

`sw.js` を編集したときは、中の `CACHE` の番号（`fm-v2` など）を上げてください。

## 注意

- 問題は学習用に作成したもので、公式の過去問ではありません。
- 税額・上限額・期限などの数値は法改正で変わります（Teil III は 2026年時点）。試験前に最新情報を確認してください。
- 模擬試験は本番の出題形式・配点を再現したものではありません。
